# Использование ИИ

## ЛР 1

**Инструмент:** Claude (Anthropic), чат-ассистент с доступом к папке проекта.

### Для чего использовался

| Задача | Как именно |
|---|---|
| Разбор задания и лекции | Сопоставление требований ЛР 1 с ноутбуком лекции, выбор траектории и уровня |
| Проектирование | Предложение структуры пакета, контрактов (Protocol), формата ошибок и отчёта |
| Код | Генерация модулей `src/school_lab/` по согласованной структуре |
| Тесты | Генерация тестов, включая контрактные и тесты закрытия файла |
| Данные | Составление `invalid_submissions.jsonl` и `assignments.json`; корректные сдачи взяты из лекции |
| Документация | Черновик README и разбор теории для подготовки к защите |

### Что проверено самостоятельно

- Написание модулей в `src/school_lab/`.
- Установка пакета и запуск команд `import` и `analyze` на своём компьютере (Windows, Python 3.14).
- Прохождение тестов, mypy и ruff.
- Соответствие вывода CLI ожидаемому: дубликат, конфликт, номера строк ошибок, отчёты анализаторов.
- Разбор кода по модулям и ответы на контрольные вопросы.

### Проверка корректности сгенерированного

- Тесты покрывают обязательные сценарии задания; часть проверок выполнена намеренной поломкой кода (убрана проверка `config_hash`, конфликта и закрытия файла — тесты упали).
- Данные и контракт сверены с лекцией (`schema_version = 1`, состав полей декларации, коды ошибок).

### Ограничения

- ИИ не использовался как источник истины: решения проверялись тестами и запуском.
- Секреты, токены и реальные работы студентов в запросы не передавались.
